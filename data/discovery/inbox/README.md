# Caixa de entrada de bibliotecas M3U

Envie aqui arquivos de playlists que você tem autorização para usar:
- .m3u
- .m3u8
- .txt (texto M3U)

O workflow compara esses registros com o catálogo mestre e gera `review-candidates.json`.
Nenhuma descoberta é incorporada automaticamente. Revise os candidatos antes de aprovar.
Não envie arquivos privados, tokens, credenciais ou URLs temporárias para este repositório público.
