# Playlists locais do repositório

Coloque aqui somente playlists que você tem autorização para distribuir e que não contenham credenciais, tokens privados ou links pessoais temporários.

- `cinema.m3u`: playlist principal opcional.
- O aplicativo tenta ler esse arquivo automaticamente.
- O arquivo `Cinema.m3u` do seu Gist também está configurado em `js/config.js`.

Atenção: em repositório público, os arquivos desta pasta ficam públicos. Para playlists privadas, use a importação local pela engrenagem; elas ficam no IndexedDB do aparelho e não são enviadas ao GitHub.
